## ✨ About The Project

This is my personal **3D interactive portfolio website**, designed to present my development skills and projects through a modern and immersive web experience.

Instead of using a traditional portfolio layout, I focused on creating a visually engaging interface with interactive elements, smooth animations, modern UI, and a developer-focused aesthetic.

The portfolio highlights:

- 👨‍💻 About Me
- 🛠️ Technical Skills
- 🚀 Featured Projects
- 💼 Experience
- 📊 Developer Statistics
- 🔗 Social Profiles
- 📱 Responsive Design
- 🎨 Modern UI/UX
- 🌌 Interactive 3D Experience
