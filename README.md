## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Vivek-Badoni/3d-portfolio.git
```

### 2. Navigate to the Project

```bash
cd 3d-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The portfolio will now be available on your local development server.
